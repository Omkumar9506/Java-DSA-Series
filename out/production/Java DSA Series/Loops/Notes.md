# Loop

### **for loop is a control structure used to execute a block of code repeatedly for a specific number of times**


# Why Do We Need Loops?
1. reducing repetition
2. writing shorter code
3. solving pattern problems
4. processing arrays and strings
5. implementing DSA logic
6. handling repeated input/output


## for Loop

#### > Basic Syntax
```
for (initialization; condition; update) {
    // code block to be executed
}
```
### **Initialization:** Executed once at the beginning to set a starting value for the loop counter.

### **Condition:** Evaluated before each iteration. If true, the code block runs; if false, the loop terminates.

### **Update:** Executed after each loop iteration, typically to increment or decrement the counter.

#### >Example
```
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```
